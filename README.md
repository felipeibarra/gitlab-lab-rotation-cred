# GitLab Lab · Rotación de credenciales y cuentas de servicio

Laboratorio local para practicar migraciones de identidades no humanas en GitLab con Docker Compose, microservicios, CI/CD, cambio de credenciales, rollback y retiro del acceso anterior.

GitHub almacena el código; GitLab Self-Managed local administra las identidades y ejecuta los pipelines. Nunca uses credenciales empresariales en esta práctica.

Este commit inicial prepara el repositorio para incorporar el código y la documentación del laboratorio.
