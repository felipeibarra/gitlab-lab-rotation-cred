# Evidencia para la entrevista

Esta carpeta no incluye resultados de migraciones no ejecutadas. Después de practicar, copia solo evidencia sanitizada y revisada.

Por identidad registra: ticket/owner simulado; ID legacy y nativo; membresías directas y efectivas antes/después; scopes y expiración sin valores; pipeline baseline y posterior; estado reciente del worker; resultado de prueba negativa del token antiguo; criterios y resultado de rollback cuando aplique.

Los reportes operativos aparecen en `.lab/reports/`, excluidos de Git. No copies todo `.lab`. Usa `docs/templates/change-record.md` para producir un resumen publicable. Revisa el contenido de cada archivo antes de un commit y ejecuta el scanner de secretos.
